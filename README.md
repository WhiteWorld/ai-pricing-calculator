# AI 费用计算器

> 帮助个人用户找到最省钱的 AI 工具方案

## 项目简介

面向中文个人用户的傻瓜式 AI 订阅价格对比工具。用户只需选择使用场景，系统自动计算并推荐最省钱的方案。

## 核心原则

- **极简操作**: 3步完成，无需技术背景
- **中文优先**: 聚焦国内用户习惯
- **个人导向**: 不考虑企业复杂需求
- **价值先行**: 暂不考虑变现，先服务用户
